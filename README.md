# Pick and Place Robot Arm with Arduino

## Project Overview
The Pick and Place Robot Arm with Arduino is a robotics and automation project designed to automate the process of picking up and placing objects. The system uses an Arduino microcontroller to control servo motors and operate a robotic arm with a gripper.

## Objectives
- To develop a robotic arm for picking and placing objects.
- To understand Arduino-based robotic control.
- To implement wireless control using Bluetooth.
- To reduce manual effort in object handling.
- To explore robotics and industrial automation.

## Technologies Used
- Arduino Uno
- Servo Motors
- HC-05 Bluetooth Module
- Android Application Interface
- 12V Power Supply
- Robotic Gripper

## Working Principle
The robotic arm receives commands through a wireless control interface. The Bluetooth module transfers commands to the Arduino controller. Arduino processes the commands and controls the servo motors to move the arm and operate the gripper for picking and placing objects.
